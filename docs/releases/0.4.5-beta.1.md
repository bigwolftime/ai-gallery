# AI Gallery 0.4.5 Beta 1

Early Android Beta for private, on-device photo search. The interface is Simplified Chinese; queries can be Chinese or English.

- Describe a photo to search the system gallery you have allowed the app to access.
- Analyze photos locally, skip previously indexed photos, and display relevance scores.
- Preview, long-press to select multiple images, and share through Android's system share sheet.
- Follow the system theme or choose light/dark mode.
- Download model data separately, selecting between Hugging Face and the Qiniu mirror.
- Check for updates in Settings. Independent Beta builds include Shorebird patches and APK updates.

Requires Android 8.0+ and a 64-bit ARM or x86 device. First setup requires an explicit model download of approximately 485 MB. Photos, queries and embeddings remain on the device; model downloads and update services make network requests described in the [privacy policy](https://github.com/bigwolftime/ai-gallery/blob/v0.4.5-beta.1/docs/privacy-policy.md).

This is an early Beta validated on an Android emulator. Physical-device performance, memory use and receiving-app sharing compatibility need broader testing. Analysis runs while the app is open. There is no cloud photo analysis or video search.

Application ID: `net.zonheng.aigallery`. This installs separately from the old `com.aigallery.app` test build. Existing test-build models, indexes and settings are not migrated automatically. Keep the test build if you still need its data.

Signing certificate SHA-256: `68d79f85fc5e5e63efc4eb3e3678ed1a9d8d2422040866460fd4df493a600fa8`.

Source: Apache-2.0. Third-party components retain their notices. Report problems through [GitHub Issues](https://github.com/bigwolftime/ai-gallery/issues); do not attach private photos to public issues.
